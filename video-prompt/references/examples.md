# 例子

下面两条是对比测试里用户觉得最好看的提示词。两条都只给了参考图（角色设定、无人场景），没给首帧，在 Seedance 2.5 全能参考模式下生成，16:9、720p、9 秒，每组只跑了一次。

学它们的写法：结构、机位的物理事实、按秒的动作、同时和随后、表情写成动作、声音。也要看清模型没照做的地方：这是抽卡，不是照着执行。

## 例 1：咖啡店（白天，两个镜头）

上传顺序：图片1 = 角色 A 设定图，图片2 = 无人的咖啡店场景图。

```
【风格】写实电影质感，白天，咖啡店内的自然光，柔和、低对比、低饱和，暖色木质环境。
【参考图】@图片1 是角色 A 的设定图：只参考她的脸、发型和服装，不沿用图里的角度和站姿。@图片2 是场景参考：只参考咖啡店的环境、桌椅和窗户，不沿用它的机位。
【空间与站位】A 坐在靠窗小方桌的一侧，B 坐在她对面，两人面对面。窗户在 A 的右手边。A 面前有一只白色陶瓷咖啡杯，杯里有一把小勺，杯子在她身体右前方。B：男，短黑发，深灰色西装外套，全程只露出右肩和后脑。

【镜头 1｜0–5 秒｜越肩中景，平视，固定机位】
相机在 B 的右肩后方。B 的右肩和后脑虚焦，占画面右侧前景约三分之一；A 在画面左侧到中间，拍到腰部以上，窗在画面左侧，光从左边照在她脸上。
0–2 秒：A 低头，用右手（画面左侧）捏着小勺慢慢搅咖啡，勺子轻碰杯壁。
2–3 秒：搅动停下，勺子留在杯里，右手松开勺柄，放在桌面上。
3–5 秒：A 抬眼看向 B（画面右侧前景），同时头微微抬起，表情平静。
同时，背景虚焦处，一名店员从画面右侧入画，往左走过。

【镜头 2｜5–9 秒｜切到 A 的近景，平视，正面略偏侧，固定机位】
画面里只有 A，拍到胸口以上。她在画面中央略偏左，视线看向画面右侧画外（B 的方向）。窗光从画面左侧照在她脸上，她自己的左脸（画面右侧）稍暗。
5–6 秒：表情平静，看着 B，自然呼吸。
6–8 秒：她自己的左嘴角（画面右侧）慢慢上扬，右嘴角不动；眼睛不笑，下眼睑不往上推，眼角没有笑纹，形成似笑非笑。
8–8.5 秒：眨一次眼。
8.5–9 秒：保持这个表情。

【声音】咖啡店里低声的人声，勺子碰杯壁两三下的清脆声。没有音乐，没有对白。
【不要】字幕，水印。
```

模型实际拍出来的：

- 做到了：第 5.04 秒切镜；越肩中景；店员从右往左走过；光影层次和电影感最好（用户判断）。
- 没照做：窗户跑到了画面右侧，光的方向反了；前景的 B 变成一块很暗的剪影；表情变成两边嘴角都上扬、眼睛带笑的自然微笑，不是似笑非笑。

## 例 2：雨夜车内（两个镜头，有光的变化）

上传顺序：图片1 = 角色设定图，图片2 = 无人的车内雨夜场景图。

```
【风格】写实电影质感，雨夜，低照度，高反差，胶片颗粒，浅景深，低饱和，只有红绿灯、街灯、霓虹这些光源的颜色鲜艳。车内很暗，光几乎都来自窗外。
【参考图】@图片1 是她的设定图：只参考脸、发型和服装，不沿用图里的角度和棚拍光线。@图片2 是场景参考：只参考车内的样子和雨夜的光线，不沿用它的机位。
【空间与站位】雨夜，她独自坐在驾驶座上（左舵车，驾驶座在车内左侧），车停在路口等红灯。副驾驶座和后排是空的。挡风玻璃和侧窗上满是雨水。

【镜头 1｜0–5 秒｜中景，固定机位】
相机在后排右侧座位上，高度略高于前排座椅的肩部，看向左前方的驾驶座。副驾驶座的头枕深色、虚焦，在画面右侧前景。她在画面左侧到中间，我们从她的右后方看她：后脑、右肩和右侧脸颊的轮廓，看不到正脸。她双手握着方向盘。挡风玻璃上满是雨水，前方路口红灯亮着，红光透过雨水落在她右侧脸颊和肩上，带着雨水流动的斑驳阴影。
0–1 秒：她一动不动看着前方。
1–2 秒：雨刷从玻璃底部刮过一次，又落回去。
3 秒：红灯变成绿灯，车内和她脸上的光从红色变成绿色。她没有动，车也没有走。
4 秒：远处传来一声短促的喇叭。她喉咙动了一下，咽了一口。

【镜头 2｜5–9 秒｜切到车外，近景，固定机位】
相机在车外，隔着驾驶座的侧窗拍她，拍到胸口以上，平视。侧窗玻璃上有雨滴和水痕，隐约叠着街灯的倒影，倒影不挡住她的眼睛和嘴。她脸朝画面左侧（车头方向），我们看到她的左脸，约四分之三侧脸。绿灯的绿光从画面左侧照在她脸上，靠近耳朵的一侧（画面右侧）落在暗处。
5–6 秒：她看着前方，眼眶发红，下唇微微发抖。
6–7.5 秒：一滴眼泪从她的左眼（靠近镜头的那只眼）眼角滑下，滑到脸颊中间；眉头内侧微微上抬，嘴唇微张。
7.5–8.5 秒：她闭上眼，用力吸一口气，下巴微微抬起，嘴唇抿紧。
8.5–9 秒：她睁开眼看着前方，表情绷住，眼泪留在脸上。

【声音】密集的雨打车顶声，雨刷刮过一次的声音，第 4 秒远处一声短促的喇叭，镜头 2 里她一次压抑的吸气声。没有音乐，没有对白。
【不要】字幕，水印。
```

模型实际拍出来的：

- 做到了：第 4.96 秒切镜，切过去后空间连贯；第 3 秒红灯变绿，车内的光跟着变；雨刷刮过一次；质感和电影感比锁了生图首帧的那组好（用户判断）。
- 没照做：镜头 1 的机位偏到后排中间，她的头被自己的座椅头枕挡住；镜头 2 没有"隔着侧窗从车外拍"，改成了在车内拍她的近景，有雨的车窗在她身后；哭得比写的外放（张嘴、皱脸）。
