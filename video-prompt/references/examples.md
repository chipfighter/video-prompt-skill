# 可选写法示意

仅在需要比较组织方式时阅读。以下截取用户提供的成功案例，说明不同内容可以采用不同写法；不照抄题材、篇幅、栏目或细节密度。真人片段先读[完整真人案例](live-action-examples.md)，此处保留其他写法的比较。

## 叙事推进：短句组织

当重点是剧情与情绪推进，常规镜头处理可交给模型：

```text
晨雾。山林。苗寨祭坛。
阿娜迦@图片1跪在祭坛中央。
苗银头饰缓缓戴到她头上。
老祭司举起银铃。
旁白：“苗疆圣蛊一脉，第十七代圣女。”
画面一切。曼谷校园。
她拖着行李穿过校园。
旁白：“但我跑了。”
停顿。“还跑到了泰国。”
```

这里已有场景、动作、旁白及叙事切换，不必为完整而补一套摄影参数。

## 精确动作：写必要约束

当重点是多主体、物理过程、时序或角色关系，可写得更细：

```text
五只猫按“二、二、一”紧接着被抛出，落点前后左右错开。
前一批开始落地时，后一批仍在出门。
它们带着门内给予的初速度，沿连续弧线下降，接触地面后翻滚卸力，再重新站稳。
在猫群抬头看向门的动作中，切到门下方低机位仰拍。
杜宾与缅因从黑色门内探出头颈，身体仍在门内。
```

必要时再展开各主体造型、关键落点、光线、声音和表演。长稿必须服务于真实的控制目标，不自动把这份密度套给普通日常镜头。

## 前景与后景

用户或副导演已经拍案的前后景设计要写。例如：

> 越肩中景，肩膀虚焦占右侧前景；背景中一名店员从右向左经过。

若用户没有要求、相关建议也未采纳，不为丰富画面自动增加店员、人群、车辆或遮挡。
