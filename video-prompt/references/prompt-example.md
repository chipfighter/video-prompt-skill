# 提示词写法参考

需要借鉴具体组织方式或表达方法时按情况阅读，不是每次写提示词前必须读取。以下是用户提供的单个场景样例，可参考素材用途的说明、选择性参考、机位与自然演出的写法；不照搬题材、篇幅、细节密度或每项演出安排。格式参考另列于正文，可根据实际需求调整。

```text
【风格】2D 日系 TV 动画，画风、颜色和光线照 @图片3：细线条，温暖明亮的阳光，颜色清新偏亮，阴影浅，对比柔和。
【参考图】@图片1 是女主的三视图：只参考长相、发型、发夹和服装，不沿用图里的角度、站姿和画法。@图片2 是场景参考：只参考这条古街、头顶的纸伞和阳光，不沿用它的机位。@图片3 是这个镜头的关键帧：参考它的构图、光影、颜色和她的表情神态。视频里的画面不必和它一样，按下面的动作自然地演出来就好。
【空间与站位】她走在古街中间的石板路上，朝镜头走来，白色耳机挂在脖子上。头顶挂满一排排彩色纸伞。
【镜头｜0–4 秒｜腰部以上的近景，后退跟拍，一个镜头不切】
镜头在她正前方、胸口高度，慢慢地匀速往后退，速度和她走路一样，平稳不晃，她始终在画面中间偏右。镜头后退时，头顶的纸伞一把把从画面上边进来，往街道深处退去。
开头她看着前方轻快地走；随后伞缝里漏下的彩色光斑落到她脸上，她抬头看向纸伞，眼睛慢慢睁大、亮起来，被头顶的颜色吸引得有点出神；随后嘴角扬起，嘴唇微微张开，露出又惊喜又满足的笑，同时抬起左手（画面右侧），张开手指去够光斑。光斑从她的手、脸和外套上滑过，头发和耳机跟着步子轻轻晃。几个陌生游客背对镜头往古街深处走，越来越小，长相和衣服都和她不一样。
【声音】古街的人声，纸伞被风吹动的声音，脚步声。没有音乐。
【不要】字幕，文字，水印，画面变暗，对比变强，咧着嘴傻笑，和女主长得一样的路人。
```
