# video-prompt：写 AI 视频提示词的 skill

把分镜表或聊定的视频创意，写成 Seedance、可灵、海螺/MiniMax、Veo 等视频模型听得懂的提示词。

默认情况下，大模型写视频提示词爱堆形容词和情绪词（"电影感、高质量、她很悲伤"）。视频模型不会读心，这样写出来的画面没有演技，也没有活人感。这个 skill 让 agent 用看得见的物理事实来写：相机在哪、拍到哪里、每一秒谁在做什么、表情怎么变、有什么声音。

可以单独用，也可以接在 [storyboard-preview](https://github.com/chipfighter/storyboard-preview-skill)（分镜预览）后面用。只要是能读文件的 agent 都能用（Claude Code、Codex 等）。

## 它会做什么

1. **分段**：同一场戏的几个镜头合成一次生成，让模型自己在设计的时间点切镜。镜头一路运镜穿过两个空间的、匹配剪辑前后两个镜头，也放在同一段。每段不短于所用平台单次的最短时长。
2. **列参考素材**：需要哪些角色设定图、无人场景图、道具图，每张写明只参考什么（比如"只参考脸、发型和服装，不沿用图里的角度和站姿"）。
3. **默认不给首帧**：测试里，锁给视频模型的图会被几乎原样照搬，图的质感也会原样带进视频；只给参考图、把文字写准，画面反而更自然。要不要给首帧或别的图，由你决定，agent 只提建议并说明风险。
4. **按固定结构写提示词**：风格、参考图用途、空间与站位、按镜头分时段写动作和表情、声音、少量否定词放在最后。
   - 机位用物理事实写：相机在人物哪一侧、多高、离多远，前景是什么，拍到身体哪里。
   - 动作按秒写，同时发生的写"同时"，有先后的写"随后"。
   - 表情写到眉、眼、嘴和呼吸，幅度按你要的来；没说幅度的，按最克制的一档写，因为视频模型本身容易把表情演大。
   - 真人画风说台词时，写明口型是正常讲话的样子，不嘟嘴。
5. **输出**：每段的提示词全文、上传顺序表、模型和参数建议，以及 agent 自己补的细节（单独列出，给你确认）。

`references/examples.md` 里有两条在 Seedance 2.5 上测过、效果好的提示词，并注明了模型哪里没照做。这套写法是在 Seedance 2.5 全能参考模式上测出来的，换模型时先少量试一试。

## 安装

### 最简单：让你的 AI 帮你装

把下面这句话发给你的 Claude Code 或 Codex：

```
帮我安装这个 skill：https://github.com/chipfighter/video-prompt-skill
```

它会自己下载并放到正确的位置。装好以后重开一个对话，说"帮我写这段视频的提示词"就会用上。

### 给 AI 的安装说明

如果你是收到上面这句话的 AI：把本仓库里的 `video-prompt/` 整个文件夹（包括里面的 `references/`）复制到用户的 skills 目录，然后告诉用户重开对话即可。

- Claude Code：`~/.claude/skills/video-prompt/`
- Codex：`~/.agents/skills/video-prompt/`
- 其他 agent：把 `SKILL.md` 当作说明书，`references/` 里的文件放在旁边，按需读取。

### 手动安装

在本页点 **Code → Download ZIP**，解压后把 `video-prompt/` 文件夹复制到上面对应的目录。

## 文件

- `SKILL.md`：分段、参考素材、要不要给图、提示词结构和写法、输出
- `references/examples.md`：两条测过的提示词，以及模型实际拍成了什么样
