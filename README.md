# video-prompt：写 AI 视频提示词的 skill

把分镜表或聊定的视频创意，写成 Seedance、MiniMax、可灵等视频模型的提示词。围绕用户想要的效果组织素材、镜头、演出和声音；用户有明确想法时优先遵循，用户不确定时由模型结合上下文和偏好判断。

可以单独用，也可以接在 [storyboard-preview](https://github.com/chipfighter/storyboard-preview-skill) 后使用。

模型应主动提出运镜、构图、表演、节奏和声音上的建议，也可以补充或反对用户的初步方案，说明理由并给出替代方案。用户听取建议后明确决定，就按其决定落实，不擅自替换、弱化要求或反复劝改；未采纳的建议不进入最终提示词或素材要求。用户未指定或授权模型决定的部分，结合上下文和偏好判断。

## 它会做什么

1. **组织参考素材**：按实际用途选择人物照、设定图、场景图及已有视频，按需要加入关键帧、道具图、灰模、动画预演或真人参考视频，不要求固定的素材组合。逐份说明参考哪些信息、用于哪些镜头。
2. **按需选择关键帧**：可以仅参考构图、光影、颜色、姿态或表情，不默认变成首帧或尾帧。用户可以提出要求，模型也可以主动建议；用户采纳的建议才纳入执行。
3. **设计分段和演出**：结合剧情与素材决定镜头和阶段。主动考虑打光、前景背景活动、人物表情、微表情及小动作。心理意图可以直接描述，重要的表演变化具体设计，普通生活动作按需要概括。
4. **灵活组织提示词**：没有统一格式，按内容选择连续描述、阶段时间段或分镜。时间按阶段描述，用户明确指定的时间节点照做，不自行添加精细角度或动作间隔。不设字数目标，也不以样例篇幅作为标准。
5. **交付**：完整提示词、图片与视频的上传顺序和用途；模型与参数只补新定或变更的部分，重要自主补充简短说明。交付前对照已确定的前后景活动、道具和声音，检查是否遗漏。

进入真人片段的具体设计或提示词写作时，先读取当前会话尚未读过的用户成功案例，学习其表演和摄影关系，不照搬场景与演出安排。连续动作需要更高精度时，根据连续感、准确度和预算选择概括生成、拆段，或灰模动画、表演视频参考。

## 安装

把下面这句话发给你的 Claude Code 或 Codex：

```text
帮我安装这个 skill：https://github.com/chipfighter/video-prompt-skill
```

安装时将仓库中的 `video-prompt/` 整个文件夹复制到相应目录，保留其内部文件结构：

- Claude Code，包括桌面端本地 Code 会话：`~/.claude/skills/video-prompt/`
- Codex：`~/.agents/skills/video-prompt/`
- 其他 agent：读取 `SKILL.md`，支持文件按需读取。

更新后在新会话中使用最新版。Claude 的聊天或 Cowork 技能库使用应用内的独立安装方式，本地 Code 目录不等于账户技能库。

也可以通过 **Code → Download ZIP** 下载仓库，再复制技能文件夹。

## 文件

- `video-prompt/SKILL.md`：素材选择、表演与摄影、提示词写法和交付检查。
- `video-prompt/references/live-action-examples.md`：用户反馈有效的真人案例。
- `video-prompt/references/examples.md`：按需读取的可选写法示意。
